# Phase 0 research memo — eeg-harmonize

Generated by `research/phase0/render_docs.py` from harness `results.json`
files. Narrative is the template; every quantitative claim is substituted.

**Safety.** This is conversion infrastructure, not a diagnostic. Sample clips
are designed. No patient-identifiable data is committed. TUH data are not
present in this repository.

---

## §1 Problem statement

Researchers who want to train one model on more than one public EEG dataset
spend weeks translating electrode names, sampling rates, reference schemes,
and annotation words before they write a trainer. Each lab writes that
translation slightly differently. The silent differences — a channel order
swap, a volt-versus-microvolt header, an annotation that is one sample late —
show up later as a "dataset effect" that is actually a conversion bug.

The people who pay are graduate students and anyone who tries to reproduce a
cross-dataset number. The obvious fix, "just use MNE and resample," does not
define a shared schema, does not log dropped channels, and does not make two
labs produce the same Parquet file from the same EDF.

This repo is one canonical record plus versioned adapters. Think dbt, but
for EEG.

## §2 Prior art

| Tool | What it does | Gap |
| --- | --- | --- |
| [MNE-Python](https://mne.tools/) | Read EDF/BDF/BIDS, resample, rereference | A library, not a corpus-level schema or adapter test suite |
| [BIDS](https://bids.neuroimaging.io/) / [MNE-BIDS](https://mne.tools/mne-bids/) | On-disk layout | Does not normalize TUH TCP names or CHB bipolar pairs into one record |
| [MOABB](https://github.com/NeuroTechX/moabb) | Cross-dataset BCI benchmarks | Motor-imagery focused; not clinical EEG corpora |
| [Braindecode / TUH loaders](https://braindecode.org/) | Dataset-specific readers | Each loader has its own assumptions; no shared provenance object |
| [NeuroKit2](https://neuropsychology.github.io/NeuroKit/) | Signal processing | Not an ingest layer |
| PhysioNet WFDB | Waveform I/O | Does not harmonize montages or annotation vocabularies |

MNE already reads every file this repo will read. Another tool is still
worth building because the failure is not I/O — it is silent, untested
disagreement between conversion scripts. The product is the schema, the
adapter tests, and the provenance chain.

### TUH access procedure (do this before Phase 2 adapters)

1. Open https://isip.piconepress.com/projects/nedc/html/tuh_eeg/ and read the
   current data-use terms.
2. Submit the NEDC request / agreement they list on that page (the form has
   moved over the years; use the page, not a cached email).
3. Wait for rsync credentials. Realistic wait: several business days to a
   couple of weeks. **Wait time in this environment: unmeasured.**
4. `rsync` the requested subset (TUSZ / TUAB / TUAR) to gitignored bronze
   storage. Do not commit it.
5. Write an ingest manifest: URL, retrieval timestamp, file count, sha256.

CHB-MIT and Sleep-EDF are wget/rsync from PhysioNet with no application.
Do not start a TUH download in CI.

## §5 Evaluation design

Metrics, declared before adapters are written:

- Round-trip invariants: channel count after documented drops, unit scale,
  annotation onset within 0.5 samples, polarity of a synthetic marker
- Resample fidelity: the table above, on every convert
- Cross-dataset transfer matrix of one identical simple model (Phase 3)
- Baseline: "read with MNE, resample, keep all channels" with no schema

Split: committed sample clips now; pinned corpus file lists after DUA.

**Failure condition:** the project fails if any designed silent-failure clip
(bad units, odd channels, offset annotation) converts without a named check
firing, **or** if the Phase 3 transfer matrix is indistinguishable from the
unharmonized MNE baseline (mean off-diagonal Δ accuracy ≤ 0).

## §7 Risks

| Risk | Type | Mitigation or acceptance |
| --- | --- | --- |
| TUH DUA denied or delayed | Data-access | CHB-MIT + Sleep-EDF + designed clips unblock schema work. TUH adapters wait. |
| Inventory presence ≠ file presence | Technical | Memo marks full scan unmeasured. |
| Redistributing TUH excerpts | Legal | Do not. Samples are generated. |
| Silent unit errors in the wild | Technical | `unit_scale` is a hard fail on convert. |
| BIDS `trial_type` explosion | Scope | unmappable bucket; do not guess. |
| Adoption | Scope | API ergonomics over model scores. Accepted that success is other people importing the package. |

### Highest-risk technical unknowns going into Phase 1

1. Whether a real TUH file's channel labels parse with the prefix rules
   encoded in `montage.py` (unmeasured on real TUH bytes).
2. Whether bipolar CHB-MIT channels should be re-referenced to unipolar
   10-20 or stored as canonical bipolar pairs.
3. Whether the unmappable annotation rate on real BIDS-EEG events.tsv files
   is high enough that the controlled set is decorative.
